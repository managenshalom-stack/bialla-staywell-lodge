# Bialla Staywell Lodge Website

##Overview
This is a multi-page website built for **Bialla Staywell Lodge**, a lodge/accomodation service based in West New Britain, Papua New Guinea. The site was developed as Assessment 2 for IS229 - Web Design, using semantic HTML5 and basic CSS, with no frameworks or website builders.

## Purpose & Target Audience
The website is designed for protective guests, travellers, and visitors looking for accomodation and information about Bialla Staywell Lodge, including its services, facilities, and how to make a booking enquiry.

## Pages Included
- **Home** - Introduction to the lodge and key highlights
- **About** - Background information about the lodge
- **Services** - Details of rooms, services, and facilities offered
- **Gallery** - Images showcasing the lodge and surroundings
- **Contact** - Contact details and an online booking/enquiry form

## Technologies Used
- HTML5 (semantic elements: header, nav, main, section, article, aside, footer)
- Basic CSS3 (readability and spacing only, no frameworks)
- Git & Github for version control
- Github Pages for publication
- Visual Studio Code as the development environment
